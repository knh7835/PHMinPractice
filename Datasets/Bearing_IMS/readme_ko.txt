IMS 베어링 데이터 사용 안내

1. 데이터 출처 및 시험 개요

이 데이터는 미국 신시내티대학교의 IMS(Intelligent Maintenance Systems)
센터가 Rexnord의 지원을 받아 수행한 베어링 수명시험 데이터이다.
NASA Prognostics Data Repository를 통해 공개되어 있다.

동일 축에 Rexnord ZA-2115 복열 베어링 4개를 설치하고, 회전속도
2,000 rpm과 반경방향 하중 6,000 lbf 조건에서 세 차례 수명시험을 수행하였다.

공식 배포 페이지:
https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/

원본 다운로드:
https://phm-datasets.s3.amazonaws.com/NASA/4.+Bearings.zip

데이터 인용:
J. Lee, H. Qiu, G. Yu, J. Lin, and Rexnord Technical Services (2007).
“Bearing Data Set”, NASA Prognostics Data Repository, NASA Ames Research Center.

원본에 포함된 “Readme Document for IMS Bearing Data.pdf”는 시험장치와
데이터 구성을 설명하는 공식 문서이다. 본 안내는 교재 실습을 위한 보충 설명이다.

2. 원본 파일명과 데이터 구성

원본은 MATLAB MAT 파일이 아니라 ASCII 텍스트 측정파일이다.
원본 압축파일 내부의 1st_test, 2nd_test, 3rd_test가 각각 한 번의 수명시험에
해당한다. 배포 압축파일을 중첩 해제해야 각 시험의 측정파일을 볼 수 있다.

측정파일 이름은 다음과 같이 측정 시각을 나타낸다.
  YYYY.MM.DD.HH.MM.SS

예: 2003.10.22.12.06.24
    2003년 10월 22일 12시 06분 24초에 수집한 신호

파일명에 .txt 확장자가 없어도 내용은 텍스트 숫자 데이터이다.
각 파일에는 20,480행의 진동 샘플이 있으며, 열은 센서 채널을 나타낸다.
참고로 Python 배열의 열 번호는 0부터 시작하므로 채널 5는 data[:, 4]이다.

1차 시험: 공식 README 기준 측정파일 2,156개, 파일당 8개 채널
  채널 1, 2: 베어링 1
  채널 3, 4: 베어링 2
  채널 5, 6: 베어링 3
  채널 7, 8: 베어링 4
  시험 종료 시 베어링 3의 내륜 결함과 베어링 4의 전동체 결함이 보고되었다.

2차 시험: 공식 README 기준 측정파일 984개, 파일당 4개 채널
  채널 1~4: 각각 베어링 1~4
  시험 종료 시 베어링 1의 외륜 고장이 보고되었다.

3차 시험: 공식 README 기준 측정파일 4,448개, 파일당 4개 채널
  채널 1~4: 각각 베어링 1~4
  시험 종료 시 베어링 3의 외륜 고장이 보고되었다.

측정 간격은 10분이며, 1차 시험의 처음 43개 측정파일은 5분 간격으로 수집되었다.

공식 README의 샘플링 주파수는 20,000 Hz이나 실제는 초당 20,480개가 기록되어 있다. 
공식 문서에서는 이를 약 1초의 신호로 설명한다.

3. 교재에서 사용하는 데이터

교재의 대표 사례는 다음 두 가지이다.

  IMS_1st_ch5: 1차 시험의 채널 5
               베어링 3의 내륜 결함 사례
  IMS_2nd_ch1: 2차 시험의 채널 1
               베어링 1의 외륜 결함 사례

ch5는 베어링 5가 아니라 센서 채널 5를 뜻한다.

실습 편의를 위해 동일 채널의 측정신호를 시간순으로 모아 채널별 MAT
파일로 구성하였다. 현재 노트북은 다음 배열 방향을 전제로 읽는다.
  행: 1회 측정에서 얻은 샘플 갯수
  열: 총 측정 사이클 수

3장: 진동신호에서 특징을 추출하고 특징 CSV를 생성한다.
4장: 진동신호를 이용하여 이상감지를 수행한다.
7장: 3장에서 생성한 특징 CSV로 건전성 인자를 구성하고 잔여수명을 예측한다.
케이스에 따라 초기 구간 또는 마지막 구간 일부를 제외하며 이는 각 노트북 별로 확인한다.

4. 폴더 내 파일의 구분

  IMS_*.mat: 원본 신호를 채널별로 구성한 교재 실습용 파일
  info.mat: 샘플링 주파수, 샘플 수, 회전속도, 베어링 형상 등의 메타데이터
  *_features.csv: 노트북에서 추출한 특징 데이터
  *.gif, *.mp4: 노트북에서 생성한 결과 애니메이션

5. 다른 시험 또는 채널을 사용하는 방법

원본을 내려받은 후 다음 절차로 다른 사례를 준비할 수 있다.

  1) 원하는 시험 폴더와 채널을 선택한다.
  2) 측정파일을 파일명에 표시된 시각순으로 정렬한다.
  3) 각 파일을 읽고 선택한 채널의 열을 추출한다.
  4) 추출한 신호를 열 방향으로 쌓아 하나의 배열로 구성한다.
  5) 파일명과 내부 변수명을 일치시켜 MAT 파일로 저장한다.
