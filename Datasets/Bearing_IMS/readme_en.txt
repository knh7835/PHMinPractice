IMS Bearing Data Usage Guide

1. Data Source and Test Overview

This dataset contains bearing life-test data collected by the Intelligent
Maintenance Systems (IMS) Center at the University of Cincinnati, USA,
with support from Rexnord. It is publicly available through the NASA
Prognostics Data Repository.

Three life tests were conducted with four Rexnord ZA-2115 double-row bearings
mounted on a common shaft, at a rotational speed of 2,000 rpm and under
a radial load of 6,000 lbf.

Official distribution page:
https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/

Original download:
https://phm-datasets.s3.amazonaws.com/NASA/4.+Bearings.zip

Data citation:
J. Lee, H. Qiu, G. Yu, J. Lin, and Rexnord Technical Services (2007).
“Bearing Data Set”, NASA Prognostics Data Repository, NASA Ames Research Center.

The original package includes “Readme Document for IMS Bearing Data.pdf”,
the official document describing the test rig and data organization.
This guide provides supplementary information for the textbook exercises.

2. Original File Names and Data Organization

The original measurements are ASCII text files, not MATLAB MAT files.
The folders 1st_test, 2nd_test, and 3rd_test within the original archive each
correspond to one life test. Extract the nested archives to access
the measurement files for each test.

Each measurement file is named using its acquisition timestamp:
  YYYY.MM.DD.HH.MM.SS

Example: 2003.10.22.12.06.24
         Signal acquired on October 22, 2003, at 12:06:24.

Although the file names have no .txt extension, their contents are numeric
text data. Each file contains 20,480 rows of vibration samples, with columns
representing sensor channels. Python column indices start at zero, so
channel 5 corresponds to data[:, 4].

Test 1: 2,156 measurement files according to the official README;
        eight channels per file.
  Channels 1 and 2: Bearing 1
  Channels 3 and 4: Bearing 2
  Channels 5 and 6: Bearing 3
  Channels 7 and 8: Bearing 4
  At the end of the test, an inner-race defect in Bearing 3 and a rolling-element
  defect in Bearing 4 were reported.

Test 2: 984 measurement files according to the official README;
        four channels per file.
  Channels 1–4: Bearings 1–4, respectively.
  At the end of the test, an outer-race failure in Bearing 1 was reported.

Test 3: 4,448 measurement files according to the official README;
        four channels per file.
  Channels 1–4: Bearings 1–4, respectively.
  At the end of the test, an outer-race failure in Bearing 3 was reported.

The measurement interval is 10 minutes, except for the first 43 measurement
files in Test 1, which were collected at five-minute intervals.

The official README specifies a sampling frequency of 20,000 Hz, whereas
20,480 samples per second were actually recorded. The official document
describes each recording as approximately one second of signal data.

3. Data Used in the Textbook

The textbook uses two representative cases:

  IMS_1st_ch5: Channel 5 of Test 1.
               Inner-race defect in Bearing 3.
  IMS_2nd_ch1: Channel 1 of Test 2.
               Outer-race defect in Bearing 1.

The label ch5 means sensor channel 5, not Bearing 5.

For convenience, recordings from the same channel were assembled in
chronological order into channel-specific MAT files. The current notebooks
expect the following array orientation:
  Number of rows: Number of samples in one recording.
  Number of columns: Total number of measurement cycles (recordings).

Chapter 3: Extracts features from vibration signals and generates feature CSV files.
Chapter 4: Performs anomaly detection using vibration signals.
Chapter 7: Uses the feature CSV files generated in Chapter 3 to construct a
           health indicator and predict remaining useful life.
Some initial or final recordings are excluded depending on the case.
Refer to each notebook for the specific exclusions.

4. Files in This Folder

  IMS_*.mat: Textbook exercise files containing original signals organized by channel.
  info.mat: Metadata such as sampling frequency, sample count, rotational
            speed, and bearing geometry.
  *_features.csv: Feature data extracted by the notebooks.
  *.gif, *.mp4: Result animations generated by the notebooks.

5. Using Other Tests or Channels

After downloading the original dataset, prepare another case as follows:

  1) Select the desired test folder and channel.
  2) Sort the measurement files by the timestamps in their file names.
  3) Read each file and extract the column for the selected channel.
  4) Stack the extracted signals as columns of a single array.
  5) Save the array as a MAT file, using the same name for the file stem
     and the variable stored inside it.
