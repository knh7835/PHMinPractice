KAU 베어링 데이터 사용 안내

1. 데이터 출처 및 시험 개요

한국항공대학교(KAU)의 베어링 진동 데이터이다. 정상 및 인공 내륜 결함
상태에서 측정한 신호로, 신호처리 방법 비교를 위해 사용한 데이터이다.

시험베어링은 원통롤러베어링 NSK NJ2306이며, 내륜에 와이어 커팅으로
폭 0.3 mm의 결함을 가공하였다. 회전속도는 1,000 rpm이다.
샘플링 주파수는 51.2 kHz, 측정시간은 파일당 1초이다.
시험장치와 센서 위치는 교재 2.3.6절을 참조한다.

2. CSV 파일명과 데이터 구성

  Normal.csv: 정상 상태, 하중 200 kgf
  Innerrace_1.csv: 내륜 결함, 무부하
  Innerrace_2.csv: 내륜 결함, 하중 200 kgf
  Innerrace_3.csv: 내륜 결함, 무부하

각 CSV 파일은 헤더 없는 51,200행 × 4열의 수치 데이터이다.
1열은 시간(s), 2~4열은 세 곳의 센서에서 측정한 진동 신호이다.

3. 교재에서 사용하는 데이터

2장에서는 신호처리 실습 위해 Innerrace_2.csv를 사용한다. 이중에서

  2열(data[:, 1]): 센서 1 신호 -> 결함 인가한 시험베어링의 신호
  4열(data[:, 3]): 센서 3 신호 -> 정상 지지베어링의 신호

즉 정상 신호는 별도 Normal.csv가 아니라 Innerrace_2.csv의 센서 3 신호이다. 
따라서 센서 1의 결함진동이 센서 3까지 전달될 수 있다.

4. 폴더 내 파일의 구분

  Normal.csv, Innerrace_1.csv, Innerrace_2.csv, Innerrace_3.csv: 실습용 CSV

5. 데이터 읽기 및 다른 측정 사례 사용

Normal과 Innerrace_2는 하중 200 kgf, 나머지 두 파일은 무부하이므로
서로 다른 파일을 비교할 때 하중조건도 함께 확인한다.
