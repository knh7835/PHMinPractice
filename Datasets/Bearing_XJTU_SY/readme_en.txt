XJTU-SY Bearing Data Usage Guide

1. Data Source and Test Overview

This dataset contains accelerated bearing life-test data provided by
Xi’an Jiaotong University (XJTU), China, and Changxing Sumyoung Technology
Co., Ltd. (SY). It includes vibration signals from the start of testing
through failure for 15 LDK UER204 bearings.

Official dataset description and download information:
https://biaowang.tech/xjtu-sy-bearing-datasets/
https://github.com/WangBiaoXJTU/xjtu-sy-bearing-datasets

Original download:
https://drive.google.com/open?id=1_ycmG46PARiykt82ShfnFfyQsaXv3_VK

Data citation:
Biao Wang, Yaguo Lei, Naipeng Li, and Ningbo Li (2020).
“A Hybrid Prognostics Approach for Estimating Remaining Useful Life of Rolling
Element Bearings”, IEEE Transactions on Reliability, 69(1), 401–412.
DOI: 10.1109/TR.2018.2882682.

This guide provides supplementary information for the textbook exercises.

2. Original File Names and Data Organization

Five bearings were tested under each of the following three operating conditions,
for a total of 15 bearings.

  Condition 1: Rotational speed of 2,100 rpm (35 Hz); radial load of 12 kN.
  Condition 2: Rotational speed of 2,250 rpm (37.5 Hz); radial load of 11 kN.
  Condition 3: Rotational speed of 2,400 rpm (40 Hz); radial load of 10 kN.

The original vibration data are CSV files, not MATLAB MAT files.
After extracting the archive, measurement files can be found in folders
organized by operating condition and bearing.

Bearing folder names follow the format Bearing{condition number}_{bearing number}.
Example: Bearing2_1 represents the first bearing tested under Condition 2.

Measurement files within each bearing folder are named 1.csv, 2.csv, 3.csv, etc.,
in measurement order. Each file contains 32,768 vibration samples in two columns:
  Column 1: Horizontal vibration acceleration
  Column 2: Vertical vibration acceleration

The sampling frequency is 25,600 Hz. Every minute, a 1.28-second recording
containing 32,768 samples is saved in one file.

3. Data Used in the Textbook

The textbook uses two representative cases:

  XJTU_2_1_ch2: Vertical vibration signal of Bearing2_1.
                Inner-race defect case; 491 recordings.
  XJTU_2_5_ch2: Vertical vibration signal of Bearing2_5.
                Outer-race defect case; 339 recordings.

Both cases correspond to Condition 2. In the file names, 2_1 and 2_5 denote
the first and fifth bearings under Condition 2, respectively; ch1 denotes
the horizontal signal and ch2 the vertical signal.

For convenience, recordings from the same bearing and direction were assembled
in measurement order into individual MAT files, with the following orientation:
  Number of rows: Number of samples in one recording.
  Number of columns: Total number of recordings.

Chapter 3: Extracts features from vibration signals and generates feature CSV files.
Chapter 7: Uses the feature CSV files generated in Chapter 3 to construct a
           health indicator and predict remaining useful life.

4. Files in This Folder

  XJTU_2_1_ch1.mat through XJTU_2_5_ch1.mat:
    Horizontal vibration signals under Condition 2.
  XJTU_2_1_ch2.mat through XJTU_2_5_ch2.mat:
    Vertical vibration signals under Condition 2.
  info.mat: Metadata such as sampling frequency, samples per recording,
            rotational speed, and bearing geometry.
  *_features.csv: Feature data extracted by the notebooks.
  *.gif, *.mp4: Result animations generated by the notebooks.

The rotational frequency fr=37.5 Hz in info.mat corresponds to 2,250 rpm
under Condition 2. When adding data from another operating condition,
the rotational frequency must be adjusted accordingly.

5. Using Other Bearings or Directions

After downloading the original dataset, prepare another case as follows:

  1) Select the desired operating condition and bearing folder.
  2) Sort the CSV files by the numeric values in their file names.
     Example: 1.csv, 2.csv, ..., 10.csv.
  3) Read each file and extract column 1 for the horizontal signal
     or column 2 for the vertical signal.
  4) Stack the extracted signals as columns of an array with 32,768 rows.
  5) Save the array as a MAT file, using the same name for the file stem
     and the variable stored inside it.
     If the operating condition differs, also adjust the rotational frequency
     and other relevant information.
