FEMTO Bearing Data Usage Guide

1. Data Source and Test Overview

This dataset contains accelerated bearing life-test data collected by the
FEMTO-ST Institute in France using the PRONOSTIA test rig. It was used in
the IEEE PHM 2012 Data Challenge and is also available through the NASA
Prognostics Data Repository.

Rather than introducing artificial initial defects, bearings were subjected
to rotation and loading to induce degradation while vibration and temperature
were measured.

The challenge dataset consists of six training bearings and eleven test bearings.
The training data cover the bearings' lives until failure, whereas the challenge
test histories were truncated before failure for remaining-life prediction.
The distribution containing complete test histories must be distinguished from
the truncated challenge test data.

Official distribution page:
https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/

Original download:

The official challenge document, “IEEEPHM2012-Challenge-Details.pdf”, describes
the test rig, measurement conditions, and original file organization.
This guide provides supplementary information for the textbook exercises.

2. Original File Names and Data Organization

There are three operating conditions, with seven, seven, and three bearings
tested under each condition, respectively.

  Condition 1: Rotational speed of 1,800 rpm; radial load of 4,000 N.
  Condition 2: Rotational speed of 1,650 rpm; radial load of 4,200 N.
  Condition 3: Rotational speed of 1,500 rpm; radial load of 5,000 N.

The original vibration data are CSV files containing ASCII numeric data,
not MATLAB MAT files. Extract the downloaded archive and any nested archives
to locate the measurement files for each bearing.

Bearing folder names follow the format Bearing{condition number}_{bearing number}.
Example: Bearing1_4 represents the fourth bearing tested under Condition 1.

Vibration files within each folder are named acc_00001.csv, acc_00002.csv, etc.
The number indicates the measurement sequence; the acquisition time is recorded
inside the file. Each file contains 2,560 rows and six columns:
  Column 1: Hour
  Column 2: Minute
  Column 3: Second
  Column 4: Microsecond
  Column 5: Horizontal vibration acceleration
  Column 6: Vertical vibration acceleration

The sampling frequency is 25,600 Hz. Every 10 seconds, a 0.1-second recording
containing 2,560 samples is saved in one file.

3. Data Used in the Textbook

The textbook uses two representative cases:

  d1_x: Horizontal vibration signal of Bearing1_1.
        Array size: 2,560 rows × 2,803 columns.
  d4_x: Horizontal vibration signal of Bearing1_4.
        Array size: 2,560 rows × 1,428 columns.

Both cases correspond to Condition 1. The labels d1 and d4 are the case names
used in the textbook; x denotes the horizontal signal and y the vertical signal.

For convenience, recordings from the same case and direction were assembled
in measurement order into individual MAT files, with the following orientation:
  Number of rows: Number of samples in one recording.
  Number of columns: Total number of recordings.

Chapter 2: Loads the two representative vibration cases and displays the raw
           signals through failure.
Chapter 3: Extracts features from vibration signals and generates feature CSV files.
Chapter 7: Uses the feature CSV files generated in Chapter 3 to construct a
           health indicator and predict remaining useful life.

4. Files in This Folder

  d1_x.mat, d1_y.mat through d7_x.mat, d7_y.mat:
    Horizontal and vertical vibration signals for each case under Condition 1.
  info.mat: Metadata such as sampling frequency, samples per recording,
            rotational speed, and bearing geometry.
  *_features.csv: Feature data extracted by the notebooks.
  *.gif, *.mp4: Result animations generated by the notebooks.

The rotational frequency fr=30 Hz in info.mat corresponds to 1,800 rpm
under Condition 1. When adding data from another operating condition,
the rotational frequency must be adjusted accordingly.

5. Using Other Cases or Directions

After downloading the original dataset, prepare another case as follows:

  1) Select the desired operating condition and bearing folder.
  2) Select only acc_*.csv files and sort them by file number.
  3) Read each CSV using its actual delimiter.
  4) Extract column 5 for the horizontal signal or column 6 for the vertical signal.
  5) Stack the extracted signals as columns of an array with 2,560 rows.
  6) Save the array as a MAT file, using the same name for the file stem
     and the variable stored inside it.
     If the operating condition differs, also adjust the rotational frequency
     and other relevant information.
